<h1 align="center">DeepTunnel</h1>
<p align="center"><b>Private mesh. Public edge. One tunnel.</b></p>

DeepTunnel joins your machines into a private mesh network and publishes any service on it to the
internet through the same tunnel: the private side of Tailscale and the public side of
Cloudflare Tunnel in one product. No open inbound ports, no second tool.

**Status:** in development.
